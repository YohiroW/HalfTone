# HalfTone Studio

[English](README.md) | [简体中文](README.zh-CN.md)

HalfTone Studio 是一款在浏览器中运行的程序化半色调图案编辑器。组合网点图案、标量场、原色图片和图片轮廓，即可导出 SVG、PNG 作品，或保存为可继续编辑的项目。

图片处理、渲染、导出和项目存储均在浏览器本地完成。应用没有后端，不会上传原始图片。

## 功能

- 圆形、方形、菱形，以及自定义 SVG 或透明 PNG 网点图案。
- 均匀、线性渐变、径向渐变、波浪、环形和噪声场，可独立设置强度与混合模式。
- 方形与交错网格，可调整间距、旋转、尺寸和明暗曲线。
- 通过随机种子重现网点的位置、旋转和尺寸变化。
- 保留原色的 PNG、JPEG 和 WebP 图片图层，支持在画布上移动和调整尺寸。
- 图片轮廓网点衬底，以及按透明通道裁切的网点叠加效果。
- 图层排序、复制、显隐、不透明度和混合模式；图片锁定与导出开关。
- SVG、PNG 导出，包含素材的 JSON 项目，以及自动保存、撤销和重做。
- 英文与简体中文界面，记住语言偏好。
- 可折叠的桌面面板、适用于窄屏的紧凑布局和键盘导航。

## 快速开始

使用 Node.js 24.x，或 22.12 及以上的 Node.js 22.x，并安装 npm。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，通常为 <http://127.0.0.1:5173/>。

构建生产版本：

```sh
npm run build
```

静态站点生成在 `dist/` 目录中，可通过静态 Web 服务器托管。部署到子目录时，请将 Vite 的基础路径设置为对应的部署路径。

## 界面语言

打开 **File → Language（文件 → 语言）**，选择 **English** 或 **简体中文**。首次使用默认显示英文。切换即时生效，无需刷新；同一浏览器会为当前站点记住选择。

菜单、控件、工具提示、通知、错误信息、预设和系统默认名称都会跟随语言切换。旧项目中可识别的默认名称也会以当前语言显示，但不会改写保存的原始名称。用户自定义名称和导入的文件名保留原文。

## 工作区与基本流程

1. 打开 **预设**，或选择 **文件 → 新建项目**。应用预设会替换当前作品，可通过撤销恢复。
2. 在左侧选择图层。下方的 **场** 区域只列出该图层所属的场，使用 **添加场** 增加新的场。
3. 在属性面板的 **当前选择** 页签中调整 **图案**、**网格** 和 **外观**。选择一个场可编辑其分布、强度和混合模式，点击 **返回图层** 回到图层设置。
4. 展开 **图案库** 导入自定义图案，或展开 **随机变化** 为各个网点添加变化。
5. 使用 **添加图层 → 图片图层** 导入原始素材，并按需创建图片轮廓。
6. 打开属性面板的 **画布** 页签，设置尺寸、宽高比、背景颜色和透明背景。
7. 点击 **导出** 生成 SVG 或 PNG，或选择 **文件 → 保存项目** 下载可编辑副本。

桌面工具栏中的面板按钮可折叠图层和属性面板。窄屏下使用底部的 **图层**、**作品** 和 **属性** 按钮切换面板，作品始终保留在编辑区域上方。

使用 Tab 在控件之间移动焦点。图层或场的选择行获得焦点后，可用上下方向键及 Home/End 导航。焦点不在输入框内时，按 **Ctrl/Cmd+Z** 撤销，按 **Ctrl/Cmd+Shift+Z** 重做。对话框将键盘焦点限制在内部，关闭后焦点返回打开它的按钮。

## 保存与导出

编辑器会将当前项目自动保存到浏览器的本地存储，并在再次打开时恢复。此记录与浏览器和站点地址绑定，不会在设备之间云同步。使用 **文件 → 保存项目** 下载可移植的 `.halftone.json` 备份，再通过 **文件 → 打开项目** 在其他浏览器或设备中恢复。导入的素材包含在项目文件内。

| 格式      | 内容                                                                              |
| --------- | --------------------------------------------------------------------------------- |
| 项目 JSON | 可编辑的图层、场、设置和内嵌素材。                                                |
| SVG       | 网点与 SVG 图案保留为矢量；PNG 图案和原色图片以位图形式嵌入。                     |
| PNG       | 在导出限制内，以 1×、2× 或 4× 倍率生成位图。启用 **画布 → 透明背景** 可去除背景。 |

隐藏的图层不会出现在作品导出中。关闭图片的 **包含在导出中** 开关，可将参考图保留在项目中，同时从 SVG 和 PNG 导出中排除。SVG 混合效果在其他编辑器中可能有所不同。

## 图片图层

图片图层保留原始颜色和 Alpha 透明通道。使用选择工具选中未锁定的图片后：

- 拖动图片可移动位置。
- 拖动边缘控制点可拉伸宽度或高度。
- 拖动角点可等比缩放；按住 Shift 拖动边缘也可保持比例。
- 调整尺寸过程中按 Escape 可取消此次缩放。
- 在属性面板中精确设置位置、尺寸、旋转、不透明度和混合模式。
- 使用 **重置尺寸** 恢复原始宽高比和适应画布的尺寸，同时保持位置与旋转角度。
- 使用 **图片居中**、**适应画布** 或 **填满画布** 调整摆放。

**锁定图片** 可防止修改图片位置和变换。**包含在导出中** 决定可见图片是否参与作品导出。这两项设置均随项目保存。

## 自定义图案

展开 **图案库 → 导入图案**，选择 SVG 或透明 PNG。SVG 图案在 SVG 导出中保留为矢量；PNG 图案使用其 Alpha 通道作为蒙版，并以图层颜色着色。

导入 SVG 前，请将文字转换为路径，避免外部图片、外部样式表、滤镜和不受支持的蒙版。如果不希望 PNG 的整个矩形区域成为图案，请先确保图片具有透明背景。

使用 **裁去透明边距** 去除空白边缘。此操作影响所有使用该素材的图层，点击 **恢复** 可移除裁切。

## 图片轮廓

选中图片并点击 **创建轮廓网点**，可在图片下方添加粉色网点衬底。要关联已有网点图层，请展开 **图片轮廓**，选择 **源图片**。

- **轮廓外扩**：保留轮廓内部的网点，让外围网点在衰减范围内逐渐缩小。调整 **外扩距离** 和 **衰减范围**，将图片置于网点上方即可露出衬底。标量场仍会影响网点大小。
- **内部裁切**：根据源图片的 Alpha 通道裁切完整图案，保留半透明效果。将网点置于图片上方可制作叠加效果。
- 轮廓跟随图片移动、旋转和非等比缩放，网点网格仍固定在画布坐标系中。
- **轮廓偏移 X/Y** 以画布像素为单位独立移动轮廓，图片和网格不动。X 正值向右，Y 正值向下。两种模式均支持偏移，设置随项目保存，旧项目默认为零。点击 **重置轮廓偏移** 可将两轴归零。
- 隐藏或不参与导出的源图片仍会提供 Alpha 通道。删除源图片后，关联的网点会隐藏，直到重新关联图片或选择 **无**；撤销删除会恢复关联。

不规则轮廓需要透明 PNG 或 WebP。不透明图片会产生矩形轮廓，该功能不会自动移除背景。外扩距离通过最长边不超过 2048 像素的缓存近似距离图计算，预览与导出共用此结果。SVG 外扩网点仍为矢量，内部裁切模式则嵌入 Alpha 图片蒙版。

## 使用限制与浏览器支持

| 项目           | 限制                                               |
| -------------- | -------------------------------------------------- |
| 画布           | 每边 64～4096 像素                                 |
| 图层           | 合计最多 8 个                                      |
| 场             | 每个网点图层最多 8 个                              |
| 素材           | 每个项目最多 32 个                                 |
| 候选网格单元   | 最多 50,000 个                                     |
| 自定义图案导入 | 最大 5 MB；PNG 图案另有 1,600 万像素限制           |
| 原始图片导入   | 最大 20 MB、1,600 万像素；同时检查解码后的图片大小 |
| 项目文件导入   | 最大 64 MB                                         |
| PNG 导出       | 每边最多 8192 像素，总计最多 1,600 万像素          |

导入图片时，还会检查编码后的项目素材总量是否超过 48 MB。若预览超过网点数量上限，请增大网格间距或隐藏部分图层。

浏览器工作流已在桌面 Chrome 和 Edge 中测试，包含紧凑布局和触控布局。尚未验证 Safari 和 iOS 真机。

## 开发与验证

项目使用 React、TypeScript、Vite 和普通 CSS。运行两组浏览器测试需要在本机安装 Chrome 和 Edge。

```sh
npm test
npm run test:e2e
npm run build
```

- `npm test`：验证图案生成、随机变化、轮廓、图片变换、项目数据和本地化。
- `npm run test:e2e`：验证编辑、持久化、导入导出、键盘交互、响应式布局和语言切换。Playwright 会启动或复用本地开发服务器。
- `npm run build`：执行 TypeScript 检查并生成生产构建。

`dist/`、`test-results/`、Playwright 报告和 TypeScript 缓存等生成文件不纳入版本控制。

| `src/i18n.ts`              | 语言偏好、插值、错误提示与默认名称本地化 |

| `src/*.test.ts`            | 单元测试                                 |
| `tests/`                   | 浏览器工作流测试                         |
