# HalfTone Studio

程序化网点 / 自定义单元图案编辑器。所有生成、素材处理和工程保存均在浏览器本地进行，没有云端上传或后端服务。

## 启动

需要现代 Node.js（建议 Node 22.12+）和 npm。

```powershell
cd G:\BrainStorm\HalfTone
npm install
npm run dev
```

打开终端显示的地址，默认 http://127.0.0.1:5173/。生产构建：`npm run build`，产物在 `dist/`，可托管到普通静态服务器。不要直接双击 index.html。

## 使用

1. 从“预设库”选择起点，或新建工程。
2. 左侧选择网点图层，在右侧设置形状、间距、尺寸、旋转和颜色。
3. 点击“上传你的图案”，导入 SVG 或透明 PNG。也可从工程素材库复用素材；每个图层拥有自己的颜色。
4. 左侧添加或选择生成场。场列表从下向上运算，上方场对下方结果继续混合。首个启用场作为基础，其混合模式不参与计算，但强度生效。
5. 径向渐变、同心波选中后，可在“选择”工具下直接拖动画布设置中心；“平移”工具用于移动视图。
6. 导出 SVG / PNG；“保存工程”下载包含全部素材与参数的 JSON，“打开工程”恢复编辑。工程每次更改后会自动保存到当前浏览器的 IndexedDB。

快捷键：Ctrl+Z 撤销，Ctrl+Shift+Z 重做，Esc 关闭弹窗。连续滑动一次计为一条撤销记录，保留最近 60 次操作。预设切换和新建工程也可以撤销。

## 图案单元

- SVG 支持路径、基本形状、分组、变换、填充、描边、镂空和显式透明度。统一使用图层单色。
- 文字需转轮廓；复杂滤镜、蒙版、外链、CSS 样式表及嵌入图片不在第一版支持范围。导入失败会指出原因，当前工程保持不变。
- PNG 用透明通道作为遮罩，忽略原 RGB 并按图层颜色着色。半透明边缘保留。白底不会自动去除，不透明 PNG 会形成矩形单元。
- “单元尺寸”表示归一化边界最长边，保持宽高比；网格角度和单元旋转相互独立。
- 默认保留文件原有留白。“裁去透明留白”根据透明度边界裁切，SVG 大尺寸素材采用最多 1024 像素采样近似边界，可以还原。该操作会同步影响复用此素材的图层。
- SVG 单元导出后仍是矢量，通过 symbol/use 复用。PNG 单元导出到 SVG 时内嵌图片，不自动矢量化。

## 图片图层

左侧“添加图层”选择“图片图层”，导入 PNG、JPG 或 WebP。图片整张显示，保留原色和透明度，不参与网点生成，也不会被图层颜色重新着色。

- 默认居中、等比适应现有画布；新增图片位于最上层。通过图层的上移/下移按钮，可放在网点下方作为底图或上方作为素材。
- 选中图片，在“选择”工具下直接拖动；右侧可输入中心 X/Y、等比缩放和旋转角度。“居中图片”只调整位置，“适应画布”完整显示，“铺满画布”覆盖画布并裁去超出部分，后两者都考虑旋转。
- 选中框有 8 个缩放控制点：左右边中点只调整宽度，上下边中点只调整高度，四角保持当前宽高比。按 Shift 拖动边中点也会等比缩放；缩放过程中对侧控制点固定，旋转和画布缩放后操作仍一致。拖过对侧时限制最小尺寸，不会翻转图片。
- 一次拖动计为一次撤销；Esc 或触控取消会恢复拖动前状态。锁定图片或切换平移工具时隐藏缩放控制点。控制点获得焦点后可用方向键微调，Shift 加速。
- 右侧 W/H 显示实际像素宽高，可分别输入数值；“图片缩放”滑块同时缩放两个方向，保持当前比例。“适应画布”和“铺满画布”也保持当前比例，包括之前的非等比拉伸。
- “锁定图片”锁定拖动、尺寸、角度与替换操作，仍可调节透明度、混合方式、显隐和导出状态。
- “参与导出”默认开启。关闭时仅工作台显示，PNG / SVG 均排除此图片，工程文件仍保留它。隐藏的图片也不导出。
- 图片支持正常、正片叠底、滤色，按统一图层顺序与网点合成。PNG 输出最终合成图；SVG 内嵌原色位图，无外部图片依赖。画布选择框不进入导出。
- 替换图片保留摆放中心、角度及显示宽高；图片数据随工程保存和自动恢复，不依赖原文件。旧工程中的单一缩放值自动迁移为相等的水平和竖直缩放值。
- 为保持输出稳定，图片导入时转成静态 PNG；动态 WebP 只保留解码时的一帧。单张源文件最多 20 MB、1600 万像素，转换后数据最多 32 MB；导入图片时检查工程素材总量不超过 48 MB。上传和转换全部在本机完成。
- 图片和网点合计最多 8 个图层。旧工程没有图层类型时按网点图层读取，原效果不变。

## 随机扰动

选中网点图层，在右侧“网格与尺寸”下方找到“随机扰动”。默认关闭，旧工程自动补充关闭设置，不改变原作品。

- 开启后默认旋转幅度为 ±45°，可调至 ±180°。每个单元在基础旋转角度上独立增加随机角度，适合箭头、花瓣等非中心对称的 SVG / PNG 图案；圆形旋转不会产生可见变化。
- 位置扰动 0–100%：单元在原网格中心周围的圆盘内均匀随机偏移，最大半径 = 网格间距 × 百分比。
- 大小扰动 0–100%：对生成场给出的尺寸应用 1±百分比的随机缩放，可超过原最大尺寸。位置、大小默认均为零。
- 固定种子保持结果可复现；“重新随机”更换种子。关闭开关恢复规则排列，再开启保留原种子和参数。
- 随机值按网格单元索引生成，各通道独立；修改某一幅度不会重新打乱其他通道。生成场仍在原网格位置采样，位置扰动不重新采样明暗。
- 参数支持撤销、工程读写和自动保存；Canvas、PNG、SVG 使用同一份逐单元旋转、位置和尺寸。

## 限制

- 8 个图层，每个网点图层 8 个生成场；工程素材库最多 32 个素材。自定义网点单元文件不超过 5 MB，独立图片图层采用上方的图片限制。
- 画布每边 64–4096；最多 50,000 个候选网格单元（包含为旋转和边缘覆盖生成的余量），超限显示提示。
- PNG 导出 1× / 2× / 4×，最长边 8192 像素、总像素 1600 万。超限倍率禁用。
- 预览与导出共用实例几何，Canvas / SVG 的抗锯齿可能略有不同；第三方 SVG 编辑器对混合模式支持不一，精确外观可用 PNG。
- 面向桌面 Chrome / Edge，窄屏采用画布在上、面板在下的布局。
- 暂无图片驱动生成场、动画、无缝平铺、CMYK 印刷分色和路径绘制器。

## 实现

- React + TypeScript + Vite；Canvas 2D 预览，逐层缓冲合成。
- 生成流程：网格坐标 → 标量场采样和混合 → 色调曲线 → 面积插值尺寸 → 图案实例 → 渲染 / 导出。
- 交错网格采用等距三角点阵，行距为间距的 √3/2。网格旋转前按画布反向变换计算覆盖范围。
- 尺寸映射为 `sqrt(min² + t * (max² - min²))`；场的数值越大，单元越大。不同形状或重叠情形不保证相同视觉覆盖率。
- 固定 simplex-noise 版本及种子算法；`Project` 同时记录格式版本和生成器版本。
- 几何按图层参数缓存；自定义素材按颜色、裁切和分辨率缓存图章。SVG 图章预览采用超采样，SVG 导出保留路径。
- DOMPurify 与 SVG 白名单限制导入内容；导出素材内嵌，不依赖外部链接。

主要模块：`model.ts`（数据/预设）、`engine.ts`（生成）、`assets.ts`（素材）、`render.ts`（渲染/导出）、`storage.ts`（验证/保存）、`main.tsx`（工作台）。

## 验证

```powershell
npm test
npm run test:e2e
npm run build
```

浏览器测试使用本机安装的 Chrome 和 Edge，不需要额外下载浏览器。单独运行其中一个：
`npm run test:e2e -- --project=chrome`（如果本机 npm 不转发参数，可使用 `npx playwright test --project=chrome`）。

自动化覆盖：27 项内核与图片变换测试，以及 Chrome / Edge 各 12 项浏览器测试。包含网点编辑、随机扰动、素材导入、图片摆放与锁定、8 点缩放、对侧固定、比例约束、旋转/缩放视图、撤销与取消、合成顺序、参考图排除导出、透明度、工程恢复、旧工程兼容和 Canvas / SVG 输出一致性。

本机初次测量（900×900 输出，包含生成和绘制，不等同于持续交互帧率）：

- 双色预设，10,154 个候选单元：约 5–6 ms。
- 噪声场，42,025 个候选单元：约 19–33 ms。
- 各设备性能会不同；复杂 SVG 路径也会增加素材解码与图章准备成本。

浏览器测试产物在 `test-results/`（截图和样例导出）。运行新一轮测试会重建该目录。
